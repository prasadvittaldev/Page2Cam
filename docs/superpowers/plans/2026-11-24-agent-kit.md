# Agent kit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Built-in and user overlay templates with live parameter updates, saved scenes, 24 playbooks, and their delivery to every agent (guide tool, MCP resources/prompts, richer instructions, Claude Code skill), the control page and the docs.

**Architecture:** `p2c-overlay` gains the template model (`template.rs`, built-ins embedded from `templates/`), the `P2C` runtime, a user template store and a scene store; the layer kind `template` renders in the same sandboxed frame as `html` layers and receives parameter changes by `postMessage`. A new platform-free crate `p2c-guide` holds playbooks and how-tos (Markdown under `content/`) and generates instructions, guide topics, resources, prompts, skill files and `docs/agent-guide/`. `p2c-mcp` uses it for `guide`, resources and prompts; the tray writes the skill; the engine and admin expose templates and scenes.

**Tech Stack:** Rust 2021, serde_json, axum 0.8, `qrcode` 0.14/0.15 (MIT/Apache, `default-features = false`), plain JS in the sandboxed frame.

**Spec:** `docs/superpowers/specs/2026-11-24-agent-kit-design.md` (builds on `2026-11-22-overlay-layers-design.md`).

## Global Constraints

- Template code (built-in or user) runs only inside `<iframe sandbox="allow-scripts">` (opaque origin, `LAYER_CSP`); params are JSON data; built-in templates and the runtime never use `innerHTML`, `outerHTML`, `insertAdjacentHTML` or `document.write`.
- Built-in templates use Segoe UI / system fonts only; no web fonts, no runtime downloads.
- User templates: at most 200, HTML ≤ 256 KB, ids `a-z0-9-` (≤ 40), never a built-in id. Scenes: at most 100.
- Nothing extra runs while no layer is visible (overlay idle pause unchanged); a visible template layer costs the same as an `html` layer.
- `instructions` ≤ ~60 lines; guide topics ≤ ~8 KB each.
- Layers loaded from a scene show as saved; after an engine restart every layer is hidden.
- New deps GPL-3.0-compatible and listed in `packaging/THIRD_PARTY.txt`.
- Skill files only under `<home>/.claude/skills/page2cam/` with marker `.page2cam-skill`, only if `<home>/.claude` exists; tests use temp dirs only.
- Commits: plain messages, no AI attribution.

## Review Focus

- A user template deleted while a layer uses it: the layer shows a "template missing" placeholder, `list_layers` reports `template_missing: true`, nothing crashes (Task 2 test `missing_template_is_reported`).
- Params that try to break out (`</script>` in a text param, `javascript:` URL, oversize data URI): embedded JSON escapes `<`, URLs are http(s) only, data URIs only `image/*` ≤ 1 MB (Task 1 test `params_are_checked`, Task 2 test `layer_page_escapes_params`).
- Live update arriving before the frame's runtime is ready: the scene re-posts the latest params on the frame's `load` event (render test step `template_live_update`).
- Loading a scene whose image layer asset or template is gone: the rest loads, the reply names what was skipped (Task 3 test `scene_load_skips_missing`).
- A non-Page2Cam `~/.claude/skills/page2cam` folder (no marker): left untouched, reported as an error (Task 6 test `skill_never_touches_foreign_folder`).

### Task 1: Template model, runtime and built-in catalogue

**Files:**
- Create: `crates/p2c-overlay/src/template.rs`, `crates/p2c-overlay/src/qr.rs`, `crates/p2c-overlay/templates/_runtime.js`, `crates/p2c-overlay/templates/<id>.json` + `<id>.html` (≈48 built-ins), `crates/p2c-overlay/src/builtin.rs` (the `include_str!` table)
- Modify: `crates/p2c-overlay/Cargo.toml` (qrcode), `src/lib.rs`

**Interfaces (produces):**
- `pub enum ParamType { Text, Longtext, Number, Bool, Colour, Choice, List, Table, Datetime, Duration, Url, Asset, Qr }` (serde lowercase).
- `pub struct Param { name, r#type: ParamType, default: Value, help: String, required: bool, min/max: Option<f64>, options: Vec<String>, columns: Vec<String>, max_items: Option<usize> }`.
- `pub struct Template { id, name, category, description, params: Vec<Param>, html: String, rect: [f32; 4], full_frame: bool, example: Map, update: Map, builtin: bool }`.
- `Template::all_params(&self) -> Vec<Param>` (own params + common `theme` choice news/minimal/brand default `brand`, `accent` colour default "").
- `Template::check_params(&self, given: &Map) -> Result<Map>` (validates every given value; unknown names refused naming the field and listing known ones; required params must be present and non-empty; numbers clamped; colours normalised; duration accepts seconds or `m:ss`/`h:mm:ss`; datetime ISO `YYYY-MM-DDTHH:MM[:SS][Z|±hh:mm]` or `HH:MM`; url http(s) ≤ 2048; asset http(s) URL or `data:image/(png|jpeg|webp|gif|svg+xml);base64,` ≤ 1 MB or empty; qr text ≤ 1000; text ≤ 500, longtext ≤ 5000, list ≤ max_items (default 50) texts, table ≤ 50 rows × columns.len() cells ≤ 200 chars, numbers allowed as cells).
- `Template::effective(&self, given: &Map) -> Map` (defaults ⊕ given; each qr value becomes `{text, n, d}` from `qr::svg_path`).
- `Template::validate_meta(&self) -> Result<()>` (id rules, category non-empty, params unique, defaults and `example`/`update` pass `check_params`, html ≤ 256 KB).
- `pub fn builtins() -> &'static [Template]`, `pub fn builtin(id) -> Option<&'static Template>`, `pub const CATEGORIES: &[(&str, &str)]` (id, label): basics, time, cards, lists, data, cta, calm, software.
- `pub const RUNTIME_JS: &str`; `qr::svg_path(text) -> Result<(usize, String)>`.
- Runtime API (JS): `P2C.onParams(fn)`, `P2C.params`, `P2C.$`, `P2C.el(tag, cls, text)`, `P2C.text`, `P2C.clear`, `P2C.fmtTime`, `P2C.fmtNum`, `P2C.every(key, ms, fn)`, `P2C.tween`, `P2C.bars`, `P2C.line`, `P2C.donut`, `P2C.qr(el, v)`, `P2C.code(el, src, lang)`, `P2C.asset(v)`, `P2C.safe`; it sets `--accent --fg --bg --bg2 --fg2 --muted` and `body.theme-<x>`; reads initial params from `<script type="application/json" id="p2c-params">`; accepts `message` events from `window.parent` shaped `{p2c:"params", params}`.

### Task 2: Template layers, user template store, live updates in the scene

**Files:** Modify `crates/p2c-overlay/src/{layer.rs,set.rs,scene.rs,lib.rs}`; create `src/store.rs`.

**Interfaces:**
- `Content::Template { template: String, params: Map }`; `KINDS` gains `"template"`; `kind_fields("template") = ["template","params"]`.
- `pub struct TemplateLib` (Clone; built-ins + optional user dir; `new(dir: Option<PathBuf>) -> (TemplateLib, Vec<String> /*dropped*/)`, `get(id) -> Option<Template>`, `list(category: Option<&str>) -> Vec<Template>`, `save(def: Value) -> Result<Template>` (create or replace a user template; built-in ids refused; 200 limit), `delete(id) -> Result<()>`, `export(id) -> Result<Value>`), `MAX_USER_TEMPLATES = 200`.
- `LayerSet::set_templates(lib)`; `LayerSet::templates() -> &TemplateLib`.
- `LayerSet::add` for `template`: requires `template` (known id), geometry defaults from `rect` (full-frame → 0,0,1,1), params via `check_params`. `update` merges `params` partially (`null` removes → default) and re-checks; `template` may change (params re-checked against the new one).
- `LayerSet::layer_json(&Layer) -> Value` and `layers_json() -> Vec<Value>` (adds `template_missing: true` when unknown).
- `state_json`: template layers carry `params` (effective) and `pv` (params hash); their `v` = hash of template id + template html.
- `LayerSet::layer_page(id) -> Option<String>`: html → `scene::layer_page(fragment)`; template → `scene::template_page(&tpl, &effective)`; missing → `scene::missing_page(id)`.
- `scene.rs`: `template_page(tpl, params) -> String` (runtime + params JSON with `<` escaped as `\u003c` + template html); `missing_page`; `SCENE_JS` builds template layers as sandboxed iframes, posts params on `pv` change and on iframe `load`.
